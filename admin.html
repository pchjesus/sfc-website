Studio 사용 안내 / Quick start

처음 사용하는 운영진

승인된 운영 계정 전용입니다. 공개 홈페이지는 로그인 없이 이용합니다. 실제 공개 허가를 받은 콘텐츠만 게시하세요.

  1. 게시글 → 새 글 작성 또는 문서로 글 작성 → 임시저장.
  2. 미리보기에서 PC·모바일 폭, 원문 및 공개 허가 확인.
  3. 게시하기 → 체크리스트 → 즉시 또는 미래 시각 예약 확정. 예약에는 파일을 연결하지 않습니다.

저장·오류·복구

임시글 자동저장과 이 탭의 복구본은 다릅니다. 저장 충돌이면 서버 최신본과 비교 후 수동으로 해결하세요. 공개글의 편집은 명시적 게시 전까지 공개본을 유지합니다. 복구본은 파일 bytes나 닫힌 탭 전체를 복원하지 못합니다. 발행 실패 시 입력을 유지하고 서버 상태부터 확인하세요.

파일과 보안

공개 버킷에는 승인된 최종 PDF·이미지와 작성 전 지원서만 올립니다. 공개 파일 URL은 게시 취소 후에도 남을 수 있습니다. 백업 JSON에는 미공개 글·관리자 정보가 들어가며 Auth·파일 원본은 포함되지 않습니다. 모의 검증은 실제 보안 검증이 아닙니다.
