- Added four composite Chromium mock cases to browser-check.py: per-work recovery (including incomplete new drafts), lost insert acknowledgement / same ID, public upload boundary / local PDF / Ctrl+S, sign-out during save. Mock tracks upload calls and simulates duplicate PK, not actual RLS or PDF rendering.

Future reserved posts with attachments are blocked intentionally until private file workflow; existing published assets cannot be retroactively made private. Stable ID prevents duplicate rows but not duplicate uploaded files. No production testing.
