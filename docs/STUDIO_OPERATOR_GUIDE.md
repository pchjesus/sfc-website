# SFC Studio 운영 안내 — Readiness D candidate
이 문서는 보고서 없이 구현한 기능의 사용 원고이며 실제 운영 권한이나 발행 검증 완료를 의미하지 않는다.

## 빠른 시작
1. 승인된 운영 계정으로 로그인. 공개 홈페이지에는 로그인 필요 없음.
2. 새 글 또는 Research Importer: 승인된 외부 AI에서 지침으로 JSON을 받아 가져오기, 오류/근거 검토, 필드 선택. 첫 수동 임시저장. 직접 AI/API 미연결.
3. 제목·요약·본문·저자 등을 직접 검토. 미리보기에서 PC/모바일 폭과 원문 확인. 임시저장은 파일 bytes를 업로드하지 않는다.
4. 게시하기에서 공개 허가 확인. 즉시/예약(현지/KST/UTC) 확인. 예약 파일 불가.
5. 승인된 게시물은 비로그인 화면 및 직접 URL 별도 확인. 게시 취소/휴지통은 글을 숨기나 공개 파일 URL은 남을 수 있다. 공개글 복구에도 재검수.

## 탭별 안내
- Posts: 검색·상태·정렬, 새 글·복제·템플릿, 서식 취소/다시 적용(일반 텍스트 전체 undo 아님), 수정 이력과 서버 비교. 자동저장과 브라우저 복구본은 다르며 파일 bytes/닫힌 탭 복구 미지원. 충돌 시 원본과 입력 보존, 강제 덮어쓰기 금지.
- Site: 홈페이지 소개/공식 문의 문구 수정, preview 확인 후 저장. 디자인 변경은 GitHub.
- People / Activities: 공개 여부·표시 순서·이름/역할/교육 단계와 내용 관리. 다중 관리자 CAS 미지원. 실명/사진/일정은 동의와 승인 후.
- Recruitment: 모집 상태/기간/대상/안내와 승인된 빈 양식. 작성 완료 지원서는 공개 업로드 금지.
- Accounts: 기존 Auth 계정 승인 및 회수, 최대 3명. 실제 계정 생성/개발자 migration/MFA 별도 승인.
- Developer: 배포 SHA 미확인, 읽기 전용 진단, 개인정보 없는 결과 JSON. 테스트 Workspace는 합성 데이터이며 실제 권한 검증 아님.
- Backup: v2 SHA-256 및 구조 검사, v1 호환. 미공개 자료 포함; Auth/파일 bytes/개발자 계정 제외. 여러 조회 결과이며 원자적 스냅샷 아님. 운영 복원 기능 없음.

## 오류 처리 / 인수인계
저장 실패 시 입력 보존, 충돌은 서버 최신본 비교. 파일 업로드/게시 실패 분리; 고아 후보는 삭제하지 말고 서버 상태 확인. 민감자료를 공개 PR·Actions·preview에 넣지 않는다. 실제 Auth/RLS/Storage와 첫 공식 보고서는 NOT RUN. 검증 증거 및 SHA는 CURRENT_BASELINE.md와 QA 문서 참조. 최종 PDF는 실제 운영 검증 후 제작.
