# Society Identity intake template — proposed fields, no actual data

- President: confirmed name, role, term, approved photograph, alt text, approved message, explicit consent date/scope; withdraw and replacement procedure.
- Other People: name, responsibility, term, short bio, photo only if approved; order and visible flag. No private contact details.
- Activities: distinguish planned curriculum from completed activity records. Completed record includes approved date, summary, outcomes, publication consent and media; not a future schedule.
- Recruitment: confirmed eligibility, capacity, meeting, start/end/time zone, selection stages, FAQ, official contact and blank PDF/DOCX. Completed application forms remain private.
- Future schema fields (photo/message, consent metadata, plan/actual distinction, expanded FAQ) require approved data contract, RLS, migration and rollback; not stored in current UI or DB. No fabricated identities or files.
