# SFC v2.8 준비 — 로딩·전환 모션 및 기능 검수

상태: **계획 문서 / 아직 구현하지 않음.** v2.7 배포가 기준. 현재의 사진과 색·레이아웃·정보 노출은 바꾸지 않는다. 승인 없이 본문을 가리거나 지연시키는 인트로 연출을 넣지 않는다.

## 1. v2.7 모션 현황 검수

- 공통 화면 진입: `js/motion.js`의 `page()`, opacity 0.35→1, 기본 520ms(Recruitment 570ms). 7개 화면이 사실상 같은 진입 방식.
- 섹션 진입: IntersectionObserver threshold .06, `rise`는 14px Y+opacity, 기본 780ms, `unveil`은 clip-path 950ms. 이미 본 콘텐츠는 다시 등장시키지 않는 구조.
- HTML 초기 요소: Home unveil 1/rise 2, About unveil 1/rise 6(딜레이 3), Research rise 1, Activities rise 1, People rise 3, Recruitment rise 3, Updates rise 3/fade 1. 목록을 동적 생성하는 JS는 별도 확인.
- 슬라이드: 기존 사진 opacity 및 이미지 확대 약 10초, 자동/수동 진행 표시. 유지.
- 필터·목록: 고유 키 기반 요소 이동/교체(FLIP) 구현. 빠른 연속 클릭·역순 선택·스크롤 복원을 기존 테스트에서 계속 검증할 것.
- 사용자 동작: About 과정 탭 교체에 소규모 7px 움직임; Activities 주차 펼침; Recruitment PDF 다이얼로그는 별도 애니메이션. 중요한 콘텐츠를 숨길 정도로 시작 애니메이션을 길게 늘리지 않는다.
- `prefers-reduced-motion`에서는 동작을 끄는 현재 정책 유지.

## 2. 권장 방향: 같은 모션을 모든 화면에 반복하지 않기

| 화면 | 현행 유지 | v2.8 선택적 제안 | 가드레일 |
|---|---|---|---|
| Home | 사진·10초 확대·슬라이드 버튼 | 첫 진입은 제목과 CTA만 80ms 간격 소규모 순차 등장; 아래 간결한 WHY SFC는 한 번만 짧은 페이드 | 사진에 2중 확대/시차 효과 금지 |
| About | 단계별 그래픽과 선택 탭 | 사진 소개의 헤드라인→본문 3개 줄을 40–70ms 간격 순서대로, 세 그래픽은 가벼운 stagger | 3줄은 항상 즉시 읽을 수 있어야 함; 애니메이션 전에 감추지 않기 |
| Research | 검색·정렬·그리드·Reader/레이블 | 초회 목록은 30–45ms 간격(상한 150ms) 등장; 재검색에서는 높이/위치 변화 위주 | 필터 타이핑마다 전 카드 fade 재시작 금지. DEMO / EQUITY RESEARCH 읽힘 유지 |
| Activities | 현재 구조·주차·필터 | **현행 유지**; 체감 개선이 확인될 때만 탭 인디케이터 시간 소폭 조절 | 불필요한 리디자인과 자동 스크롤 금지 |
| People | 카드의 바로 읽히는 역할/업무 | 첫 화면에 들어오는 카드만 45ms 간격 약한 페이드 | 인물 사진/업무가 늦게 나타나거나 가려지지 않기 |
| Recruitment | 모집중일 때 네이비 CTA·4개 절차 노출 | 첫 진입은 기본정보 2×2만 짧게, 절차선은 필요하면 가벼운 강조 | 지원 CTA 상태 전환 즉시 반영; 입장 방해하는 로딩 연출 금지 |
| Updates | 제목·날짜·필터 | 실제 게시글 처음 노출 때만 최대 120ms 순차; 빈 상태·오류는 즉시 보이기 | 새로고침·필터 반응성 우선 |

**시작값:** 진입 300–420ms, 미세 섹션 등장 320–500ms, 탭/컨트롤 160–260ms, 스태거 간격 35–70ms(총 지연 상한 180ms). 기존 780/950ms와 비교해 *실제 체감 테스트* 후 결정. 무조건 애니메이션 가짓수를 늘리지는 않는다.

## 3. v2.8 적용 전 필수 실험

1. 별도 `preview/sfc-v2.8-motion` 브랜치에서 **기존안(A) vs 절제된 변형(B)** 두 가지. 본문 정보·이미지·CMS 로직 그대로.
2. 최초 진입/탭 왕복/빠른 연속 탭/History back/스크롤 위치 복원/검색 입력·정렬·리스트 전환/다이얼로그 취소를 1440·768·390·360px에서 테스트.
3. `prefers-reduced-motion` on/off, 키보드·포커스 표시, 느린 CPU 및 중간급 모바일에서 긴 프레임/레이아웃 떨림 확인.
4. CMS 빈 상태/실제 발행, 모집 planned/open/closed 별 캡처. 애니메이션이 AJAX 데이터 교체를 숨기거나 CTA를 늦게 노출하지 않는지 검사.
5. 스크린샷과 2~3초 실시간 녹화 비교, 사용자가 승인한 변경만 메인 반영.

## 5. 종료 기준

- 소유자 승인 전 다음 디자인을 메인에 반영하지 않음.
- 화면에서 핵심 정보를 빠르게 파악하고, 누르지 않아도 필요한 내용을 읽을 수 있음.
- **모션이 줄어든 상태에서도** 동일 정보·동작에 접근 가능.
- 모바일 가로 스크롤, 콘솔 오류, 의도치 않은 중복 제어, 폼/검색 지연 없음.
