# SFC v2.8 — 모션 개발 브랜치 검수 보고 (Preview)

작성일: 2026-11-26. 기준 메인: v2.7 `2fe54e8`. 구현: `preview/sfc-v2.8-motion`.

**중요:** 실제 모션 코드는 이 브랜치에 반영됐으나, 메인/Pages에는 **아직 적용하지 않는다**. 사용자 화면 검수 후 별도 승인 필요. 이 문서의 검증 상태는 검증 당시의 실제 수행만 기록한다.

## 전역 모션 타이밍

- 스타일 토큰: `cubic-bezier(.22,1,.36,1)`을 주요 정착, `cubic-bezier(.25,.8,.25,1)`을 표면 상태 변화에 사용. 과장된 spring/bounce 없음.
- 공통 페이지 전체 opacity 0.35→1 520ms **제거**. 데이터·링크는 처음 프레임부터 접근 가능. 비즈니스 페이지의 필요 없는 중복 reveal 축소.
- 기준: 컨트롤 약 185~260ms, 데이터 재배치 355ms, 스크롤 섹션 340~390ms, 모달 300ms, 헤더 모바일 메뉴 315ms, 기존 Home 사진 전환 1150ms 및 10초 앰비언트 확대 유지.
- reduced motion: JS 모션 skip, CSS 애니메이션/전환은 0.01ms, 진행바 사진 확대 중지.
- 발행 상태·모집 상태·데이터 없음/오류·DEMO 구분은 페이드/스태거로 지연하지 않음.

## 핵심 코드와 변경 위험

- `js/motion.js`: 공통 상위 route 페이드 삭제, reveal 우선권을 전용 연출에 넘김, FLIP·filterRows 타이밍 완화.
- `js/v2.8-motion.js` 신규: 실제 7탭 요소를 직접 대상으로 한 단일 소형 모션 모듈. 기존 state DOM을 직접 변경하지 않고 도착 상태에만 animation.
- `css/v2.8-motion.css` 신규: hover padding 흔들림 완화, 색/선/레이아웃 전환 시간 통일, 저감모션 보장.
- `js/site.js`: Home 슬라이드 변경 애니메이션 분리, 기존 타이머/일시정지/키보드 조건 유지.
- `js/about-experience.js`: 4개 단계의 SVG 동작 연결 및 빠른 연속 선택 취소. 단계 본문 키보드/ARIA/출력 내용 유지.
- `js/research-platform.js`: 결과 목록과 view-mode FLIP를 분리(같은 tick에서 재렌더링해 FLIP를 취소하지 않음), 불필요한 고스트 노드 생략.
- `js/cms-public.js`, `js/people-recruitment.js`, `js/visual-story.js`: 데이터 도착/실제 공개 구성원/모집 상태/단계 설명에 후처리 모션만 적용.
- `index.html`: 새 CSS/JS 로드, 변경된 스크립트만 2.8.0 캐시 식별자. 기존 정적 문구/사진/로고/콘텐츠 계약은 그대로.
- `tests/static-check.mjs`·`tests/browser-check.py`: 이전 v2.7 버전 고정 및 사라진 HTML 문장에 의존한 오래된 기대값 갱신, 모션 회귀 조건 추가.
- `.github/workflows/v28-preview-qa.yml`: 브랜치 및 PR의 정적/모의 CMS Playwright 테스트 구성.
